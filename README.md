# Personal Expense Tracker 💰

## About the Project

The Personal Expense Tracker is a beginner-friendly Python project developed to record and manage daily expenses.

The program allows users to enter multiple expenses, validate expense amounts, calculate total expenditure, and generate a simple expense report.

This project was developed as part of my Python programming practice in November 2026.

## Features

- Add multiple expenses.
- Store expense names and amounts using Python lists.
- Validate expense amounts (only positive amounts are accepted).
- Calculate total expenditure.
- Display the number of expenses.
- Find the highest expense.
- Find the lowest expense.
- Generate a final expense report.
- Continue adding expenses until the user chooses to stop.

## How to Run the Project

1. Install Python 3.
2. Download or clone this repository.
3. Open `expense_tracker.py` in Spyder or another Python IDE.
4. Run the program.
5. Enter your expense name and amount.
6. Choose whether to add another expense.
7. View your final expense report.
